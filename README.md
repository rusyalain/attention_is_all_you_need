# Внимание — это всё, что нужно?

Обучение небольшого декодера трансформера с нуля на русской художественной прозе. Модель содержит 29 676 544 параметра, использует контекст из 512 токенов и собственный BPE-словарь из 8192 элементов.

В репозитории находятся код, учебный ноутбук, токенизатор и итоговые веса. Корпус скачивается и обрабатывается кодом; готовые тексты и массивы токенов в Git не хранятся.

## Запуск модели

Исходное окружение: Python 3.14. Для загрузки весов нужен [Git LFS](https://git-lfs.com/).

```sh
git clone https://github.com/rusyalain/attention_is_all_you_need.git
cd attention_is_all_you_need
git lfs pull
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python demo.py --open-browser
```

В Windows окружение активируется командой `.venv\Scripts\activate`. Локальное демо открывается по адресу `http://127.0.0.1:8765/`. После загрузки весов интернет для генерации не нужен. Поддерживаются CPU и MPS.

```sh
python generate.py --prompt "Она остановилась у окна. За стеклом медленно" --tokens 160
```

Веса `checkpoints/best.pt` занимают около 119 МБ и хранятся через Git LFS. В них нет состояния оптимизатора. Проверочная SHA-256: `3e9bc5760ce7399cc494a291713a1738888ba75903b210df00ecbbd5497b86ea`.

## Ноутбук и подготовка корпуса

Откройте [transformer.ipynb](transformer.ipynb) в Jupyter или редакторе с поддержкой notebook. Он объясняет токены, attention, причинную маску, обучение и генерацию. Сохранённые измерения исходного опыта включены в ноутбук.

В разделе данных флаг `PREPARE_CORPUS = True` запускает весь конвейер:

1. Скачивание закреплённых архивов Пушкинского Дома, RusLit, РСД и текстов Lib.ru.
2. Извлечение текста, нормализацию, жанровый отбор и удаление повторов.
3. Объединение связанных произведений в группы и разделение на train, validation и test.
4. Обучение ByteLevel BPE только на train и запись токенов.

Результат появляется в `data/`. Загрузки кешируются в `data_pipeline/cache/`. Этот же процесс можно запустить отдельно:

```sh
python data_pipeline/prepare.py
python verify_corpus.py
```

Если папка уже содержит подготовленный корпус, она не перезаписывается. Архивы проверяются по закреплённым контрольным суммам. Доступность отдельных страниц Lib.ru зависит от источника; их содержимое со временем может измениться. Источники и условия использования указаны в [NOTICE.txt](NOTICE.txt).

## Обучение

Флаг `RUN_TRAINING = True` в ноутбуке запускает обучение с нуля. Если данных нет, сначала выполняется их скачивание и подготовка. По умолчанию длительные операции выключены, чтобы обычный запуск ноутбука не начинал обучение заново.

```sh
python train.py --prepare-data --hours 5.5 --run-dir runs/experiment
```

Полное обучение рассчитано на MPS. Новый запуск сохраняется в `runs/experiment`, отдельно от опубликованных весов. Число шагов за заданное время зависит от устройства.

```sh
python evaluate.py --data-dir data --checkpoint runs/experiment/checkpoints/best.pt --output-dir runs/evaluation
python -m unittest discover -s tests -v
```

## Исходный эксперимент

Корпус после очистки: 3010 записей от 172 авторов, около 593 МБ текста и 98,3 млн токенов. На принятом корпусе выполнены три прохода — 269,6 млн обучающих токенов с повторами, 4 ч 56 мин активных вычислений. Проверено на ноутбуке с 48 ГиБ памяти.

Ошибка на отложенных произведениях: 3,429 нат/токен у трансформера, 5,099 у модели соседних пар, 7,309 у частот отдельных токенов. Модель воспроизводит формы прозы, но повторяется, ошибается в согласовании и теряет сюжет. Обучения выполнению пользовательских инструкций не было.

## Публикация локальной копии

Удалённый репозиторий нужно создать на GitHub пустым, без README. В этой локальной копии уже настроен адрес `origin`. Публикация кода и весов:

```sh
git lfs install --local
git push -u origin main
```

Git LFS передаёт веса при выполнении push. Подготовленные данные, кеш, новые запуски обучения и материалы выступления исключены из Git.

Архив ZIP содержит файлы без папки `.git`. Если вы распаковали ZIP вместо работы с подготовленным локальным репозиторием, сначала создайте историю:

```sh
git init -b main
git lfs install --local
git add .
git commit -m "Initial source and trained model"
git remote add origin https://github.com/rusyalain/attention_is_all_you_need.git
git push -u origin main
```
