Источники данных и реализации

1. Корпус нарративной прозы XIX в., версия 4.0.
   Собчук, Олег; Лекаревич, Евгения.
   DOI: https://doi.org/10.31860/openlit-2020.10-C004
   Репозиторий Пушкинского Дома, файл 5915 (texts.zip).
   Лицензия набора, указанная в метаданных издателя: CC0.
   Исходные библиографические сведения сохранены в data_pipeline/snapshot/source_metadata.

2. RusLit, d0rj.
   https://github.com/d0rj/RusLit
   Commit: 4509680428729da225a73a22008133660f92bb7e.
   README источника объявляет тексты общественным достоянием.
   Использована только проза с дополнительной жанровой фильтрацией.

3. Русский стилеметрический датасет, Борис Орехов, 2026.
   DOI: https://doi.org/10.5281/zenodo.20701309
   https://github.com/nevmenandr/RSD
   Commit: 476876e8a5c430fb0f6e147bf1519c9b43699261.
   Использованы только записи author/fiction, перечисленные в corpus.tsv.
   Источник объявляет литературные тексты общественным достоянием.
   Раздел «Лицензия» README и файл LICENSE указывают GPL-3.0 для метаданных,
   структуры и вспомогательных скриптов. Исходная лицензия сохранена в
   source_licenses/RSD-GPL-3.0.txt. Данные о происхождении RSD и производные
   сведения из его таблиц сохраняют атрибуцию и эти условия.
   В FAQ того же README также осталось упоминание CC BY-SA 3.0 для метаданных;
   исходный README сохранён целиком, чтобы не скрывать это расхождение.

4. Lib.ru / Классика.
   http://az.lib.ru/
   Использован фиксированный список 42 авторов и отбор по жанру.
   URL каждой текстовой записи сохранён в manifest.jsonl.
   Электронные источники и сведения о печатных изданиях сохранены там, где
   они доступны в исходных метаданных. На весь объединённый корпус не
   объявляется новая единая лицензия, заменяющая условия источников.

Изменения данных: извлечение основного текста HTML, нормализация Unicode и
пробелов, удаление отдельных редакторских примечаний, жанровая фильтрация,
выбор версий и удаление дубликатов, объединение связанных текстов в группы,
разделение train/validation/test, обучение собственного ByteLevel BPE.
Преобразования не делают эту коллекцию полным собранием сочинений каждого автора.

Архитектурные источники:

Bahdanau et al. Neural Machine Translation by Jointly Learning to Align and
Translate (2014): https://arxiv.org/abs/1409.0473
Bengio et al. A Neural Probabilistic Language Model (2003):
https://jmlr.org/papers/v3/bengio03a.html
Devlin et al. BERT (2018): https://arxiv.org/abs/1810.04805

Справочная реализация семейства GPT: nanoGPT, Andrej Karpathy,
https://github.com/karpathy/nanoGPT (MIT).
Изучались стандартные приёмы связывания весов, масштабирования остаточных
проекций и реализации causal attention. Код модели в этом проекте написан
для данного эксперимента на PyTorch. Готовые веса, токенизаторы и эмбеддинги
не использовались. PyTorch и tokenizers сохраняют собственные лицензии.
